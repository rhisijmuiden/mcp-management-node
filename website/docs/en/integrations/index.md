# Integrations overview

**Integrations → All integrations** shows every connection of Stackpilot with its state, so you see at a glance what is
working, what expires soon and what is not set up yet:

| Integration | What it gives you | Guide |
| --- | --- | --- |
| **Agents** | Proxmox nodes, servers and workstations | [Agents and pairing](../machines/agents.md) |
| **AI apps** | Claude, ChatGPT, Copilot over MCP | [Connect your AI](../ai/connect.md) |
| **MCP servers** | Other MCP servers behind the same address | [MCP hub](../ai/mcp-hub.md) |
| **Microsoft 365** | Users, licences, MFA and risky sign-ins per customer | [Microsoft 365](m365.md) |
| **UniFi** | Networks, Fabrics, WiFi and door access | [UniFi](unifi.md) |
| **GitHub** | Software library, new repositories, deployments | [GitHub](github.md) |
| **Mail server** | Every mail Stackpilot sends | [Mail server](../admin/mail.md) |
| **App backups** | Backups of Stackpilot itself | [App backups](../admin/backups.md) |

## Set up step by step

Click **Set up step by step** on an integration. A guide opens with numbered steps:

- direct links to the right page at GitHub, Microsoft or UniFi;
- what to tick or fill in there;
- the place in Stackpilot where you paste the result and finish.

Dashed tiles on a customer overview open the same guides, already for that customer.
