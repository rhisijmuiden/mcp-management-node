# Overzicht koppelingen

**Koppelingen → Alle koppelingen** toont elke koppeling van Stackpilot met zijn status, zodat je in één oogopslag ziet
wat werkt, wat binnenkort verloopt en wat nog niet is ingericht:

| Koppeling | Wat het je geeft | Uitleg |
| --- | --- | --- |
| **Agents** | Proxmox-nodes, servers en werkplekken | [Agents en koppelen](../machines/agents.md) |
| **AI-apps** | Claude, ChatGPT, Copilot via MCP | [Je AI koppelen](../ai/connect.md) |
| **MCP-servers** | Andere MCP-servers achter hetzelfde adres | [MCP-hub](../ai/mcp-hub.md) |
| **Microsoft 365** | Gebruikers, licenties, MFA en riskante aanmeldingen per klant | [Microsoft 365](m365.md) |
| **UniFi** | Netwerken, Fabrics, wifi en deurtoegang | [UniFi](unifi.md) |
| **GitHub** | Softwarebibliotheek, nieuwe repositories, deployments | [GitHub](github.md) |
| **Mailserver** | Alle mail die Stackpilot verstuurt | [Mailserver](../admin/mail.md) |
| **App-back-ups** | Back-ups van Stackpilot zelf | [App-back-ups](../admin/backups.md) |

## Stap voor stap instellen

Klik bij een koppeling op **Stap voor stap instellen**. Er gaat een uitleg open met genummerde stappen:

- directe links naar de juiste pagina bij GitHub, Microsoft of UniFi;
- wat je daar moet aanvinken of invullen;
- de plek in Stackpilot waar je het resultaat plakt en afrondt.

Gestippelde tegels op een klantoverzicht openen dezelfde uitleg, meteen voor die klant.
